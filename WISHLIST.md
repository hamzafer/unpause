# Wishlist

Ideas surfaced by an audit pass. Nothing here is built yet.

- Jump to a session that's already open, instead of only "fork it" or "open it again"
- Hide or archive old sessions so the list doesn't grow forever. Could pair with Open loops: marking a loop done archives the session
- Sort or group the list by project or account instead of always newest-first
- Linux tab support for other terminals (Kitty, WezTerm), and a check that Windows even builds
- Open loops: a picker view (`^o`, or `unpause next`) listing every Recap's `next` line, newest first, so you can see all unfinished work across repos. `enter` resumes the session, `^d` marks the loop done and drops it from the list
- Resume with context: opening a session starts Claude with the Recap's `next` line already typed as the first prompt, so there's nothing to re-explain
