# The tool is called unpause

The working name was `cs`, which is C#, a common shell alias, and says nothing. We checked fifteen candidates against Homebrew, npm, crates.io, PyPI and GitHub on 2026-09-07: `cs`, `ccs`, `sesh`, `ariadne`, `resume`, `rethread` and `wayback` were taken, several by tools in the same niche (`sesh` is a tmux session manager, `ccs` a Claude account switcher, `rethread` a Claude/Codex handoff tool). `unpause` was free everywhere, is a verb, and says what the tool does. Renaming a published CLI breaks installs and muscle memory, so this is fixed.
